# 功能指南

本栏目面向使用内置能力的应用开发者。

- [订阅与过滤](./subscriptions.md)：状态规则、正则、内容过滤器和取消订阅。
- [运行期管理事件源](./dynamic-sources.md)：应用启动后安全增删、暂停和恢复 Source。
- [NapCat](./napcat.md)：OneBot 事件接收与 API 调用。
- [Bilibili](./bilibili.md)：动态、直播状态和弹幕事件源。

内置适配都需要外部平台。先用[快速开始](/guide/quick-start.html)验证框架本身，
再接入真实服务，可以更快区分配置问题与生命周期问题。
