# 功能指南

本栏目回答“如何使用 ButterBot 完成具体工作”，面向应用开发者，不展开框架
内部实现。

- [CLI](./cli.md)：检查配置、启动和管理本地进程。
- [配置](./configuration/)：YAML、环境变量和运行时配置。
- [运行模式](./runtime-modes.md)：独立进程、嵌入模式和信号行为。
- [订阅与过滤](./subscriptions.md)：状态规则、过滤器和取消订阅。
- [事件源](./sources/)：内置平台、运行期管理与 API 使用入口。
- [故障排除](./troubleshooting/)：按安装、启动和异步生命周期定位问题。

内置适配都需要外部平台。先用[快速开始](/guide/quick-start.html)验证框架本身，
再接入真实服务，可以更快区分配置问题与生命周期问题。要实现新的平台接入，
请转到[扩展开发](/extensions/)；要理解内部调度与所有权，转到
[框架开发](/architecture/)。
