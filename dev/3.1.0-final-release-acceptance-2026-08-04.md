# ButterBot 3.1.0 正式发布最终验收

> 验收日期: 2026-08-04
>
> 发布版本: `3.1.0`
>
> 结论: **GO（待维护者提交、打 tag 与发布）**

## 1. 发布语义

- 已文档化且从公共门面导出的 Source、API、Data、Type、Filter 与可信 Handler
  插件作者面为 stable API。
- stable API 在 `3.x` 内遵守 SemVer：不删除名称，也不破坏现有正确调用的签名或
  语义；破坏性调整必须提升 major 并提供迁移说明。
- experimental 仅适用于文档明确标注的能力；未导出的实现和以下划线开头的名称属于
  internal API，不提供兼容承诺。
- 第三方 Source 由应用工厂显式装配，是稳定的所有权边界，不是 beta 阶段遗留限制。

## 2. 本次发布收口

- 项目元数据与锁文件由 `3.1.0b1` 升级为 `3.1.0`。
- 插件模板、示例、fixture 和 CLI 生成的 manifest 统一使用
  `requires_core = ">=3.1,<4"`。
- 文档删除当前版本的 Beta/RC/provisional 表述，并在
  `docs/api/stability.md` 定义 stable、experimental、internal 边界。
- NapCat WebSocket 认证改为 OneBot 约定的 `Authorization: Bearer <token>`，并有
  回归测试覆盖。
- 默认配置路径相关测试在临时工作目录执行，不再受维护者本地 `config.yaml` 影响。

## 3. 联调证据

- 维护者已完成 WSL2 到宿主机 Snowluma/NapCat 的联调；完整运行日志保存在
  `logs/`，未将凭据写入本记录。
- 复核中，WSL2 可连接宿主机 WebSocket 端口；携带 Bearer 认证后握手成功。
- NapCat、Bilibili 动态和直播 Source 均完成启动；首次轮询只建立基线，不推送历史
  内容。
